# Kit phase 3 — Les Délices d'Orodis

À fusionner dans le dépôt du site (Orodis-Frontend).

- public/sons/bienvenue-jour.mp3, bienvenue-soir.mp3 : voix de bienvenue (05:00–17:59 / 18:00–04:59, heure d'Abidjan), jouées au premier toucher sur /t/[token].
- public/sons/nouvelle-commande.mp3 : écran cuisine et gestion, à chaque nouvelle commande.
- public/sons/appel-serveur.mp3 : gestion, quand une table appelle un serveur ou demande l'addition.
- public/sons/tables/ : facultatif, un fichier table-N.mp3 par table (« Vous êtes à la table N »), joué après la voix de bienvenue s'il existe.
- docs/maquettes/phase3/ : maquettes validées de référence (format Claude Design ; les images /_blob/ ne s'affichent pas hors de Claude Design).

Copier aussi le document « Architecture phase 3 » (export Markdown) dans docs/phase3.md des deux dépôts.
