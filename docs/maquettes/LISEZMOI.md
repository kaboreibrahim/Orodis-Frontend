# Maquettes validées — référence pour Claude Code

Fichiers HTML des maquettes (format Claude Design). Ils servent de référence pour la mise en page, les couleurs, les textes et les animations : ce n'est pas du code à copier tel quel.

- Main.dc.html : page d'accueil complète (bienvenue, héros, bandeaux, bento, comment ça marche, traiteur, réservation, FAQ, nous trouver, pied de page, menu burger)
- Carte.dc.html : anneau des catégories et CouvertureFlow (glissement au doigt)
- Traiteur.dc.html : page Traiteur et formulaire de devis
- ResaSite.dc.html : réservation de table en 3 étapes (version téléphone)

Les images y sont référencées en /_blob/... et ne s'affichent pas hors de Claude Design : utiliser les photos de public/ ou celles de l'API.
